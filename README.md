# RideGuide — Distributions & Community

This is the **public** home for RideGuide's releases and community input. The
application source lives in a separate private repository; this repo holds only
what users need.

## Downloads & updates

Installers and update payloads are published as **[Releases](../../releases)**.
RideGuide checks here for updates automatically (Settings ▸ Data & Sharing ▸
Updates), or download the latest installer directly from the releases page.

Each release lists a SHA-256 checksum so you can verify your download.

> **Note on SmartScreen:** early builds are unsigned, so Windows SmartScreen may
> warn on first run ("More info" → "Run anyway"). This clears as the app builds
> download reputation.

## Feedback, bugs, and feature requests

Have an idea, hit a bug, or want to shape where RideGuide goes next? The app has
a built-in form — **Settings ▸ Data & Sharing ▸ Feedback & Suggestions** — that
opens a prefilled issue here in your browser. You can also
**[open an issue directly](../../issues/new/choose)**.

Everything filed here feeds the community-driven roadmap.

## Contributing game data

RideGuide supports many sim-racing titles, and each adapter is marked *verified*
only once it has been confirmed against the real game. You can help verify the
game you play — opt in from **Settings ▸ Data & Sharing ▸ Contribute game data**.
Contributions are scrubbed and anonymized on your machine before you ever share
them; nothing leaves your PC without your explicit consent.
